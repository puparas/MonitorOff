# MonitorOff

Минималистичная утилита для Windows, которая затемняет выбранные мониторы и (если поддерживается DDC/CI/WMI) снижает яркость до минимума с последующим восстановлением.

## Возможности

- Управление каждым монитором по кнопкам `M1`, `M2`, ...
- Панель на каждом подключенном мониторе
- Предпросмотр затемнения при наведении
- Управление из трея:
  - включить/выключить конкретный монитор
  - включить все
  - выключить все
  - выход
- Перетаскивание панели мышью
- Изменение размера кнопок (ПКМ по панели)
- Сохранение позиции и размера панели отдельно для каждого монитора

## Запуск

Требования:
- Windows
- .NET Framework 4.7.2

Запуск:
- соберите проект: `dotnet build MonitorOff.sln -c Release`
- запустите `bin/Release/net472/MonitorOff.exe`

## Минимальная сборка для распространения

Готовая минимальная папка: `dist/minimal`.

Содержимое:
- `MonitorOff.exe`
- `MonitorOff.exe.config`
- `MonitorOff.ico`
- `System.Resources.Extensions.dll`
- `System.Buffers.dll`
- `System.Memory.dll`
- `System.Numerics.Vectors.dll`
- `System.Runtime.CompilerServices.Unsafe.dll`

Отладочные файлы (`*.pdb`) в минимальную сборку не входят.
